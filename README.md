# City# CityRide 🚌

CityRide is a modern, responsive bus ticket booking website.

### Live Project
After publishing, your link will be: 
`https://jaddaprasanna5.github.io/city-ride/`

### Features
- Clean UI for bus booking
- Fully responsive on mobile
- Easy route selection
- Fast and simple design

### Tech Stack
- HTML5 - `city-ride.html`
- CSS3 - `city-ride.css`
- JavaScript - `city-ride.js`

### How to Run
1. Download the 3 files
2. Open `city-ride.html` in Chrome
